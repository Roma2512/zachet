# Вариант 05. Менеджер резервного копирования

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Process, async file I/O, SemaphoreSlim, хеши, Channel, IDisposable

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Получить список файлов исходного каталога.
2. Реализовать последовательное копирование.
3. Реализовать асинхронное копирование потоками.
4. Ограничить параллельные копирования через SemaphoreSlim.
5. Проверять целостность копии через SHA256.
6. Обрабатывать ошибки каждого файла и закрывать потоки.
7. Сохранять каталог назначения в HKCU.

## Дополнительные задания
8. Построить pipeline обнаружение → копирование → проверка через Channel.
9. Добавить JSON-журнал.
10. Добавить запуск внешней утилиты и ожидание её завершения через Process.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
